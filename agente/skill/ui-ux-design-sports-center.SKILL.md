This skill guides the creation of world-class user experiences and interfaces that make managing and booking sports facilities a pleasure.

## UX Research & Strategy

### User Personas
- **The Athlete**: Needs speed, clear availability, and quick booking.
- **The Facility Manager**: Needs a bird's-eye view, financial control, and easy scheduling.
- **The Team Captain**: Needs coordination tools, group booking, and payment splitting.

### User Journey Mapping
- **Discovery**: Finding the nearest court with the right surface.
- **Decision**: Comparing prices and time slots.
- **Action**: Seamless booking and secure payment.
- **Engagement**: Receiving reminders and inviting friends.

## Visual Design & Branding

### Aesthetics (The "Wow" Factor)
- **Premium Feel**: Use subtle gradients, depth through shadows, and high-quality sports imagery.
- **Color Psychology**: Use energetic greens/blues for action and calm neutrals for administration.
- **Consistency**: A robust design system ensures every button and input feels part of the same family.

### Design System Components
- **Typography Hierarchy**: Clear distinction between headers, labels, and body text.
- **Grid Systems**: Responsive grids that adapt from mobile to wide desktops.
- **Icon Set**: Cohesive, minimal icons for sports types, facilities, and actions.
- **Micro-interactions**: Subtle feedback (pulses, color shifts) for user actions.

## Accessibility & Inclusivity

### Standards
- **High Contrast**: Essential for outdoor usage under direct sunlight.
- **Touch Targets**: Minimum 44x44px for easy interaction while active.
- **Screen Reader Support**: Semantic structure and ARIA labels.
- **Color Blindness**: Don't rely solely on color for status (use icons/labels).

## Tools & Handoff

- **Design Tools**: Figma, Sketch, or Adobe XD.
- **Prototypes**: High-fidelity interactive flows to test usability before coding.
- **Documentation**: Clear specs for colors, spacing (8px grid), and component states (hover, active, disabled).

## DO NOT

- Use cluttered layouts with too much text.
- Over-complicate the booking process (aim for < 3 steps).
- Use generic stock photos; use custom or AI-generated assets that match the brand.
- Forget about empty states (e.g., "No bookings found").

Design experiences that inspire people to get out and play.
